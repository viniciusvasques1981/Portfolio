# Portfólio — Vinicius Vasques

Site em um único arquivo (`index.html`), pronto para o **GitHub Pages**.

## Arquivos

- `index.html`: o site inteiro (textos, imagens dos cases, fonte, estilos e o currículo para download).
- `Vinicius_Vasques_Curriculo.pdf`: cópia do currículo (sem telefone), para links diretos.
- `produtividade-nas-obras-com-portal-360.m4a`, `como-a-mrs-digitalizou-seus-patios.m4a` e `como-a-anglo-american-unificou-decisoes-globais.m4a`: os áudios do player dos cases da MRV&CO, da MRS e da Anglo American. Os nomes precisam ficar exatamente assim, na raiz do repositório.
- `README.md`: este arquivo.

## Publicar

1. No repositório `Portfolio`, apague os arquivos e as pastas antigos (por exemplo `assets`, `cases`, `sobre`, `privacidade`, `og-image.png`, `404.html`, `robots.txt`, `sitemap.xml`). Em cada pasta, o menu **…** tem a opção **Delete directory**.
2. Em **Add file > Upload files**, envie `index.html`, `Vinicius_Vasques_Curriculo.pdf`, `README.md` e os três arquivos `.m4a` para a raiz e confirme com **Commit changes**.
3. Em **Settings > Pages**, escolha **Deploy from a branch**, branch **main** e pasta **/ (root)**, e salve.
4. O site abre em `https://viniciusvasques1981.github.io/Portfolio/` depois de alguns minutos.

## Medição

O Microsoft Clarity (projeto `zcmxvzfp50`) já está configurado e só carrega depois que o visitante clica em **Aceitar** no aviso de cookies. O rodapé tem **Gerenciar cookies** e **Política de privacidade**. Para ativar o Google Analytics, envie o ID de medição (começa com `G-`) para que ele seja incluído no `index.html`.

## Endereços

O site usa endereços com `#`, por exemplo `…/Portfolio/#case-mrs` e `…/Portfolio/#sobre`.
